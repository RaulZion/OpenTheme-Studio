## Risks, limitations, blockers

- No implementation blocker remains in this scoped package. Native acceptance is still blocked on the controller's integration with the actual Gemini companion and real target apps. No other-agent PR review or waiting occurred.
- A successful mocked HTTP response is **not native VS Code settings proof**. Real workbench/token changes, unrelated-settings preservation and native restore need the companion/native gate. Protocol/auth/origin handling is implemented here; the extension enforces server-side origin and auth.
- A completed browser write proves CSS file I/O, not real Obsidian reload or snippet enablement. Browser cannot detect that app's process/version/state. User must choose .obsidian and enable the snippet once. Secure local Chromium and continued read/write permission are required; Firefox/Safari are not promised.
- Connection status represents the last acknowledged operation, not continuous process monitoring. If the companion disappears, the next operation times out/fails visibly and automatic sync pauses. Browser network/CORS failures may be opaque; UI gives the relevant local-origin/permission/reconnect instructions.
- Session credentials and directory handles are intentionally not persisted; reload requires reconnect. Local edits remain usable offline, but live target updates require the connection/permission. Closing/disconnecting cannot roll back a write already committed; restoration/removal are explicit actions.
- Existing snippet bytes must have the valid marker and digest to be overwritten or removed. On collision/manual edit Studio refuses rather than auto-backing up or touching foreign content. Only the named target is read for ownership; no directory enumeration, notes, other snippets or other config files.
- No new dependencies; root reconciliation is not required by this branch. Controller may still reconcile combined integration packages. No root/shared/connector/adapter change request.
- UI simplification (issue #10), broader accessibility/browser/native testing and polish remain outside OTS-143. Essential keyboard/editor regressions pass; no conformance or usability metrics claimed.
