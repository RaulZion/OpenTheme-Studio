# Evidence and technical research — 2026-11-04

## Findings and limits

- Public evidence confirms a substantial theme ecosystem and multiple existing multi-app generators, but does not quantify paying demand for a new visual editor.
- Themer already offers a web UI, CLI, API and templates for multiple apps. Its API and MIT license make it especially relevant prior art. https://github.com/mjswensen/themer
- Tinted Theming Base24/Base16 already maps schemes to application-specific templates; it demonstrates portability but not the exact desired nontechnical preview workflow. https://github.com/tinted-theming/base24
- Zed Theme Builder already supports visual preview and inspector; the experience is an important reference, but app-specific. https://zed.dev/blog/theme-builder
- Real user pain on Themer is documented in an issue about unclear accent/shade meaning and preview: https://github.com/mjswensen/themer/issues/59
- A second issue requests side-by-side previews rather than scrolling between picker and preview: https://github.com/mjswensen/themer/issues/53
- Evidence for an accessible, cross-application visual editor is **qualitative**, not representative market sizing. No customers were interviewed for this kickoff.

## High-impact finding

Blender 5.0 unified/rearranged many theme settings relative to 4.5, with imperfect migration from older themes. It is a strong reason for version-aware adapters and an initial separate feasibility spike, not an argument to discard Blender.

## Still necessary, but not blocking project planning

1. Competitive UX task-based comparison against Themer and Zed Theme Builder.
2. At least 12-15 discovery interviews with people who theme two or more apps; observe past behavior and actual pain rather than relying on idea approval.
3. Real file installation tests in at least one target version per exporter.
4. License audit for any reused code/assets, and app branding/screenshot usage prior to public release.
5. Verify target app version matrices and compatibility during every release.
